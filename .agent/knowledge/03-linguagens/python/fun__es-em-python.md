# Funções anônimas em Python# 


### Expressões lambda (às vezes chamadas de formas lambda) são usadas para criar funções anônimas. Uma função
### anônima é uma função que não é construída com o "### def###  "
e que, por isso, não possui nome. Esse tipo de
### construção é útil quando a função faz somente uma ação e é usada uma única vez.
