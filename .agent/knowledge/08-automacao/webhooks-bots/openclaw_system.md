# 🦞 OpenClaw — Cross-Platform Autonomous Assistant

> **Origem:** Baseado no repositório [`openclaw/openclaw`](https://github.com/openclaw/openclaw)
> **Finalidade:** Assistente autônomo multiplataforma com soberania total de dados pessoais. Executa ações diretamente no sistema operacional (automação de tarefas de desktop, navegação e arquivos).

---

## 📋 Diferenciais do OpenClaw

- **Soberania de Dados:** Todos os dados, logs e ações são mantidos no dispositivo local do usuário.
- **Automação Cross-Platform:** Roda em Windows, Linux e macOS com suporte a atalhos de sistema e comandos de terminal.
- **Execução Real de Tarefas:** Não apenas conversa, mas manipula arquivos, dispara scripts, gerencia janelas e orquestra fluxos no sistema operacional.

---

## 💡 Quando o Agente Deve Sugerir o OpenClaw:
1. Para usuários que desejam automações locais no desktop sem depender de nuvens externas proprietárias.
2. Integração de fluxos de trabalho híbridos (interação de sistema operacional com scripts locais).
