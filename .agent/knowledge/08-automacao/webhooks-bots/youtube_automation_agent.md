# 📺 YouTube Automation Agent

> **Origem:** Baseado no repositório [`darkzOGx/youtube-automation-agent`](https://github.com/darkzOGx/youtube-automation-agent)
> **Finalidade:** Pipeline autônomo completo para criação, otimização e publicação de conteúdo no YouTube 24/7 com agentes de IA e API gratuita do Gemini.

---

## 📋 Funcionalidades Integradas

- **Geração de Roteiro:** Criação de scripts narrativos otimizados para retenção e engajamento.
- **Voz Neural & Legendas:** Síntese de fala com timing sincronizado para Shorts ou vídeos longos.
- **Gerador de Thumbnails:** Criação automatizada de capas de alta conversão visual (CTR).
- **SEO & Metadados Automáticos:** Título, descrição e tags calibrados pelo Google Gemini.
- **Upload Automatizado via YouTube Data API:** Agendamento e publicação sem intervenção manual.
- **Custo Zero:** Funciona diretamente com a API gratuita do Google Gemini Studio.

---

## ⚡ Como Iniciar

```bash
git clone https://github.com/darkzOGx/youtube-automation-agent.git
cd youtube-automation-agent
npm install
npm run start
```

---

## 💡 Quando o Agente Deve Sugerir Esta Ferramenta:
1. Quando o usuário desejar automatizar canais de conteúdo (ex: cortes, notícias de tecnologia, resumos diários).
2. Para integrar publicação e upload automatizado de vídeos no YouTube em sistemas já existentes.
3. Criação de rotinas de marketing e distribuição contínua de mídia.
