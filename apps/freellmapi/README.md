# 🌐 FreeLLMAPI - Gateway de IA Gratuito

Servidor unificado compatível com a API da OpenAI que consolida **34 provedores gratuitos de IA** e mais de 635 endpoints de modelos.

## 🚀 Como Iniciar

### No Windows:
Basta dar um duplo clique em:
```cmd
iniciar.bat
```

### No Linux / macOS:
```bash
bash iniciar.sh
```

## ⚙️ O que o script faz sozinho:
1. Valida se o **Node.js (v20+)** está instalado.
2. Instala as dependências via `npm install` automaticamente se for a primeira execução.
3. Inicia o servidor e abre o painel web em `http://localhost:3001`.
4. Endpoint para seus agentes ou outros sistemas: `http://localhost:3001/v1`
